# 🤖 Discord Auto-Reaction Bot

Discord-бот на **C# (.NET 8)** для автоматической расстановки реакций.

## ✨ Функционал
*    **Таргетинг:** Отслеживает сообщения конкретного пользователя по ID.
*    **Авто-реакции:** Мгновенно ставит выбранный эмодзи на новые сообщения.
*   ️**Конфигурация:** Токен и настройки вынесены в JSON (безопасно для Git).
* **Продвинутое логирование:**
    *   Цветной вывод в консоль.
    *   Временные метки (Timestamps).
    *   Четкое разделение событий (`INFO`, `DETECT`, `ERROR`).
*    **Обработка ошибок:** Бот не падает, если у него нет прав ставить реакции, а корректно сообщает об этом в консоль.

## 📋 Требования
*   [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
*   Discord Bot Token (с правами администратора или правами на реакции).

## 🚀 Установка и Запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/yarmi001/DiscordReactionBot.git
cd DiscordReactionBot
```

### 2. Создание конфигурации
Файл `config.json` исключен из репозитория (`.gitignore`) для защиты ваших данных.
Создайте файл **config.json** в корне проекта и вставьте настройки:

```json
{
  "Token": "ВАШ_ТОКЕН_БОТА",
  "TargetUserId": 415540086265085953,
  "ReactionEmoji": "🐳"
}
```
*   `TargetUserId` — ID пользователя (число, без кавычек!).
*   `ReactionEmoji` — Сам смайлик (Win + .).

### 3. Настройка прав (Intents)
В [Discord Developer Portal](https://discord.com/developers/applications):
1.  Откройте вашего бота -> вкладка **Bot**.
2.  В разделе **Privileged Gateway Intents** включите:
    *   ✅ **Message Content Intent** (Обязательно!)

### 4. Запуск
```bash
dotnet run
```
